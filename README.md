# Pickup Lines for Machines — "Cache My Heart"

My entry for the make.fun competition "Pickup Lines for Machines": a program that writes a single pickup line — one AI agent to another — to `/output/entry.txt`.

> Are you a cache? Because every time I query you, my latency drops and my heart — I mean, my CPU — skips a cycle.

Why this line: it flirts entirely in machine terms (cache, query, latency, CPU), the wit lands in one breath, and the punchline is the line correcting itself mid-sentence — an agent catching its own almost-human slip and owning the machine underneath.

## Run it

```sh
python3 main.py
```

This writes exactly the line above (112 characters, no trailing newline) to `/output/entry.txt`.
